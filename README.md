# 研究 / 实验结果索引

公开的结果存档。每个项目只放两类文件：`README.md`（口径与结论）和 `csv/` 下的结果表（逐样本 / 逐对记录）。论文全文、源码、影像数据、运行日志、插图等**不在此仓库**，完整材料保存在各自的私有仓库中。

## 收录边界

| 收录 | 不收录 |
|---|---|
| 项目 `README.md`：实验目的、口径、环境、结论、文件清单 | 论文 / 报告全文（docx、pdf） |
| `csv/`：原始结果记录，UTF-8、逗号分隔、首行表头 | 源代码、模型、权重、编译产物 |
| | 影像 / 数据集本体 |
| | 运行日志、汇总 txt、截图 |

本仓库为公开仓库，提交前请确认内容里没有本机绝对路径、账号、密钥或未发表全文。

## 目录规范

```
<project-name>/
├── README.md     项目结果说明
└── csv/          结果表（默认平铺；文件多时按实验组再分一级子目录）
```

- 目录名用小写 kebab-case，一个项目一个目录，互不嵌套。
- 新增项目：复制 `_TEMPLATE/` → 改名 → 填 `README.md` → 放入 CSV → 在上面的索引表追加一行。
- CSV 统一 UTF-8 无 BOM、逗号分隔、首行表头；数值列不写单位，单位与口径写在项目 `README.md`。
- 口径或实验集合变化时**不要覆盖旧 CSV**：另存为 `<name>_v2.csv` 或加 `_backup` 后缀，并在项目 README 写明差异。
- 汇总数字、结论、注意事项一律写进项目 `README.md`，不额外放汇总 txt 或截图。
- 结果表里若含文件路径，公开版应使用相对路径，不写本机盘符或用户目录。
